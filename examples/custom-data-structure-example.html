自定义数据结构试卷生成器示例

📝 功能说明

本示例展示了如何使用自定义数据结构生成试卷PDF。你可以：

  • 使用完全自定义的字段名称
  • 注册新的题目类型
  • 自定义渲染方式
  • 灵活配置数据结构映射

⚙️ 数据结构配置

{
  "examFields": {
    "title": "examTitle",
    "subject": "subjectName", 
    "author": "creator",
    "instructions": "examInstructions"
  },
  "questionFields": {
    "question": ["content", "questionText", "题目"],
    "options": ["choices", "answers", "选项"],
    "id": ["qid", "questionId", "编号"]
  },
  "questionTypes": {
    "choice": {
      "dataField": "choiceQuestions",
      "title": "选择题",
      "description": "（共 {count} 题，每题 {score} 分）",
      "defaultScore": 5
    }
  }
}

📖 使用说明

  1. 配置数据结构：定义字段映射关系，支持多个候选字段名
  2. 准备数据：按照自定义结构准备试卷数据
  3. 生成PDF：系统自动转换数据结构并生成试卷
  4. 扩展功能：可注册自定义题目类型和渲染器
